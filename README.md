# Web-Based Exam Management System

A web application to manage exam sessions, grade entry, publication, rejection, and verbalization for professors and students.

## Features
- Role-based single-page interface (Professor / Student)
- Client-side table sorting with custom grade ordering
- Asynchronous grade insertion, publication, rejection, and verbalization
- Modal-based multiple grade entry
- Automatic generation of exam reports (verbals)

## Technologies
- **Backend:** Java, REST APIs  
- **Frontend:** HTML, CSS, JavaScript
